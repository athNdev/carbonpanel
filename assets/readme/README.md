# README artwork

`hero.html` is the editable source for `hero.png`, the 1200 × 440 root README
banner. Serve the repository locally, open this file in a browser at exactly
1200 × 440 with device scale 1, wait for the local fonts and image to load, and
capture the viewport as a PNG. No external fonts or services are required.

It reuses the approved, unmodified horizontal brand lockup, the website's local
IBM Plex fonts, and `landing/assets/graphite-world.webp`. The terrain's original
generation prompt is recorded in [artwork provenance](../../docs/homepage-artwork.md).
This banner is decorative artwork. Product images in `assets/showcase/` are
separate, unretouched captures from the running application.
