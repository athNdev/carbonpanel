The **Datapacks** tab on a server manages the world's own datapacks. Use it when
you want to install a datapack on one server. Use [Modpack Studio](/guides/modpack-studio/)
when the datapack should be part of a pack you share or deploy.

Datapacks work on vanilla servers without a mod loader, and next to any loader
that keeps the vanilla datapack folder.

## Browse and install

1. Open the server and select **Datapacks**.
2. Choose **Browse Datapacks**.
3. Search by name. Results are filtered by the server's Minecraft version.
4. Select **Install** on a result.

The archive is installed into the world's `datapacks/` folder. The Datapacks tab
uses the default `world` folder for every server.

<Aside type="note">
If your server sets a custom `level-name` in `server.properties`, the Datapacks
tab still writes to `world/datapacks/`. Move the archive into your custom world's
`datapacks/` folder with the Files tab instead.
</Aside>

## Upload an archive

**Upload Datapack** accepts a `.zip` archive. The archive must contain
`pack.mcmeta` at its root; anything else is rejected before it reaches the
world.

Datapacks are loaded when the world loads, so restart the server after
installing, uploading or deleting one.

## Manage installed datapacks

The list shows each archive's display name, pack format and file name. When the
declared pack format does not match the server version, the row carries a
warning so you can spot a datapack that will be ignored.

Delete removes the archive from the world's `datapacks/` folder. It does not
touch anything else in the world.

<Aside type="caution">
Datapacks are world data. They live inside the world folder and are included in
a default [server backup](/guides/backups/). Deleting a datapack does not remove
data it generated in the world.
</Aside>

## Datapacks in a modpack

A datapack in Modpack Studio behaves differently:

| | Server **Datapacks** tab | Studio **Datapacks** tab |
| --- | --- | --- |
| Scope | One world | The pack |
| Install target | `world/datapacks/` | The pack's datapack folder, then the world on bake |
| Options | None | Side, pin, optional, default, description |
| Sharing | No | Exported or deployed with the pack |

See [Modpack Studio](/guides/modpack-studio/) for the pack-side editor.
